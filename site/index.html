Windows 桌面版

基于 Electron 打包的原生桌面工作台，专为稳定连接各类 API 网关与大批量本地文件交付打造。

  • ✓ 无惧 CORS 跨域拦截：通过主进程受控网络通道发起请求，支持各类不支持浏览器直连的上游中转与私有网关。
  • ✓ 系统级安全凭据存储：API Key 采用 Windows 系统加密（safeStorage）持久化保存，关闭重启无需重填。
  • ✓ 本地目录直接落盘：支持直接选择电脑目标文件夹批量写出高清成图并自动防重名覆盖。

Web 在线体验版

托管于 GitHub Pages 的纯静态渐进式 Web 应用（PWA），任何电脑或平板打开链接即可体验完整交互。

  • ✓ 零后端纯静态架构：不经过任何第三方中转服务器，浏览器直接请求你所配置的上游 API 地址。
  • ✓ 会话级密钥保护：在线版 API Key 仅暂存于当前标签页 sessionStorage，关闭标签页自动销毁。
  • ✓ 支持离线缓存与安装：可一键添加至桌面应用图标，项目历史与图片缓存保存在本地浏览器。
提示：受浏览器安全沙箱机制限制，在线版要求你配置的上游 API 接口开启 CORS 允许跨域；若遇到 Failed to fetch，请改用左侧 Windows 桌面版。

FAQ

常见问题解答

软件自带免费的生图额度吗？需要准备什么才能开始使用？
跨境Image工作台是一款完全开源免费（MIT 协议）的客户端工作流工具，本身不捆绑售卖算力。你只需在右上角「设置」中填入自己的 OpenAI 官方接口、任意 OpenAI-compatible 兼容服务商（如各类聚合网关）、fal.ai 或 Seedream 接口的 Base URL 与 API Key 即可使用。
我的商品未公开新品图、五点文案和 API Key 会上传到你们的服务器吗？
绝对不会。本项目采用纯粹的本地优先（Local-First）无后端架构：所有项目草稿、参考图与历史记录均存储在你本机的浏览器 IndexedDB 中；生图与策划请求仅由你的设备直连你自行配置的 API 服务商。
为什么在 Web 在线版点击测试连接或生图提示 Failed to fetch？
部分 API 服务商未在响应头开放浏览器跨域（CORS）权限，浏览器会拦截网页直接发起的请求。遇到这种情况，只需下载安装 Windows 桌面版（或本地克隆仓库运行 npm run dev 使用内置受控开发代理）即可完美解决。
我可以把这套工作台私有化部署到团队内网、Cloudflare 或 Docker 吗？
完全支持。仓库已内置 wrangler.jsonc（一键 npm run deploy:cf 部署至 Cloudflare）、deploy/Dockerfile + Nginx 配置以及完整的 GitHub Actions 工作流，团队可在数分钟内完成私有部署。
